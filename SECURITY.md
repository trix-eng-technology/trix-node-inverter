# Security policy

## Reporting a vulnerability

Please do not report security issues in public GitHub issues.

Contact Trix Engineering and Technology Co., Ltd. through https://trix.technology/contact with the subject "Security - TRIX Deye Gateway" and include:

- the firmware version (shown on the System page of the gateway)
- a description of the issue and how to reproduce it
- any proof of concept, logs or captures

We will acknowledge your report, investigate it, and keep you informed until it is resolved. Fixes are delivered to installed gateways through signed over-the-air updates.

## Supported versions

Security fixes are provided for the latest release. Installed gateways receive updates automatically through TRIX.
